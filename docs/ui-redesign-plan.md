# UI 重设计方案（松弛书卷学习台）

> 立项 2026-11-27。方向 A「松弛书卷学习台」。**第一批（令牌 + 首页 + 答题页）已随 0.5.5+18 发布**；
> 结算 / 学习 / 错题本 / 设置 / 数独五页仍未改版，见 §7 待办。

## 1. 定位与方向

一句话定位：**「拾」是一张为孩子准备的宣纸学习桌：每次只呈现一个清楚的任务，抬手能点中，答完能看懂。**

设计优先级固定：孩子能读懂任务与状态 → 手指能稳定点中 → 答题反馈清楚但不喧闹 →
家长能快速找到设置 → 最后才是纸纹、印章等装饰。

立项时比较过三个方向（均保留宣纸 + 墨 + 朱印、不引新依赖、首页不滚动）：

| 方向 | 换来 | 牺牲 | 结论 |
|---|---|---|---|
| **A 松弛书卷学习台** | 保留识别度，解决宽屏失控、文字偏弱、答题页空洞、统计重复 | 不如绘本童趣，无强游戏刺激 | **采用**：手机与平板双场景最均衡，不需新增插画体系 |
| B 温润儿童绘本 | 更亲近低龄，英语/拼音更亲和 | 文言、文学常识偏低幼；需长期维护插画 | 若产品转向 6~7 岁可再评估 |
| C 书卷闯关路线 | 生涯目标感最强 | 闯关压过内容，快问快答被降级，首页更挤 | 不适合当前玩法结构 |

## 2. 令牌（已实施）

`lib/theme/app_theme.dart`。对比度基准是 `paper #F8F2E6`。

| 令牌 | 值 | 用途 | 对 paper |
|---|---|---:|---:|
| `paper` / `paperDeep` / `card` | 不变 | 底 / 渐变下缘 / 卡片 | 背景 |
| `ink` | 不变 `#262119` | 标题、正文、题干 | 14.33:1 |
| `inkSoft` | **`#5C5346`** | 卡片副标题、说明、未选中 tab | 6.77:1 |
| `inkFaint` | **`#6B5F4E`** | 页脚、数量、次级统计 | 5.59:1 |
| `seal` | 不变 `#A63A2E` | 主按钮、选中、当前科目 | 5.77:1 |
| `sealSoft` | 不变 | 选中卡片底、轻量朱红标签 | 背景 |
| `sealPressed` | **新增 `#823025`** | 主按钮按下态 | 7.85:1 |
| `gold` | 不变 `#B08A34` | **仅装饰**（星标、节点） | 2.88:1，禁止用于文字 |
| `goldInk` | **新增 `#765717`** | 可读的金色文字 / 数独选中格外框 | 5.99:1 |
| `jade` | **`#356044`** | 答对、已掌握 | 6.48:1 |
| `jadeSoft` | 不变 | 答对卡底 | 背景 |
| `error` | **新增 `#96372F`** | 答错、危险操作 | 6.53:1 |
| `errorSoft` | **新增 `#F5E1DC`** | 答错卡底 | 背景 |
| `line` | **`#DCCFB6`** | 非交互分隔、进度轨道、禁用卡描边 | 1.38:1，仅装饰 |
| `lineStrong` | **新增 `#9A896D`** | 可点击边界（选项、可点卡片） | 3.05:1 |
| `disabledText` | **新增 `#706555`** | 禁用文字 | 5.12:1 |
| `scrim` | **新增 `0x66000000`** | 弹层遮罩 | — |

`AppMetric`（新增）：`radiusCard 16` / `radiusButton 14` / `radiusChip 12` /
`buttonHeight 56`（短屏 `buttonHeightShort 52`）/ `optionHeight 64`（短屏 56）/
`cardPadCompact 16` / `cardPadWide 20` / 页面边距 `16 / 24 / 32`。

**两条硬规则**：
- `gold` 不做文字、不做唯一焦点框——它对纸底只有 2.88:1。
- 可点击边界用 `lineStrong`，`line` 只画非交互的东西。`card` 与 `paper` 色差很小，只用
  `line` 时卡片边界在纸底上几乎看不见（早期状态的实感）。

背景：去掉每 28px 一道的竖向水痕，渐变收在底部约 20%（`stops [0, 0.8, 1]`）。

## 3. 首页

### 已实施

- **二级科目固定四列网格（`_TopicGrid`）**。原实现用 `Wrap` + 宽屏 `width: null`，
  1280×800 下语文 8 个子科目各自占满一整行，变成 8 条全宽色块，把范围卡与玩法卡
  挤出屏幕。改为按行切分、显式等分宽度，窄屏宽屏都四列两行。
- **宽屏双栏**：左 flex 44（范围卡 / 数独关卡），右 flex 56（玩法三卡 + 主按钮 +
  次级入口 + 页脚），主体簇在页签以下的剩余空间里垂直居中。
- 玩法卡等高（`IntrinsicHeight` + `CrossAxisAlignment.stretch`，且 `Column`
  宽屏时用 `mainAxisSize.max`——`.min` 会让它不跟着拉伸）。说明文案按词义用 `\n`
  断行，避免「诗／词」这种拆词。
- 标题区删掉书本图标入口（与底部「学习模式」同目的地，重复入口只是多一次误点）。
- 范围卡改上下两段：标题行（可折两行）+ 说明行（说明 + 右对齐「调整 ›」）。
- 次级入口卡字号 13/12 → 16/14；禁用卡描边降为 `line`、文字用 `disabledText`。
- **顺手修的既有缺陷**：数独页会渲染「语文 / 数学 / 英语」一级导航却一个都没选中
  （`Topic.group` 为 `other`，原代码注释与实现矛盾）。现在 `group` 不在
  `kSubjectGroups` 里时只渲染一条分隔线。

### 决策记录

- 「玩数独」保留文字而非缩成「数独」：数独页的标题本身就是「数独」，入口与标题同名
  会让读屏和测试都分不清。
- 玩法卡宽屏允许说明折三行、不截省略号——「答对的诗词不再出现，逐步通关全库」被
  截成「答对…」就读不懂了。

## 4. 答题页

### 已实施

- 选项 tile：标准 64dp（宽屏 72），字 18pt（宽屏 20），圈字母 30dp。默认边线
  `lineStrong`，选中 `goldInk`，答对 `jade`/`jadeSoft`，答错 `error`/`errorSoft`。
  **答错不再复用 `seal`**：朱印是主按钮与「当前选中」的色，答错用它会让「确认动作」
  和「出错」看起来是同一类信号。
- **判题前后不位移**：底部操作区（反馈槽 + 主按钮）在判题前就渲染——占位是
  「选一个答案，解析会出现在这里」，按钮是禁用的「请先作答」；判题后只换内容。
- 宽屏题干限宽 560dp（原来一栏 700dp 时四五个字被撑成又宽又扁的长条），并与右侧
  选项组视觉中心对齐。

### 踩过的坑（改动前必读）

宽屏曾试过「把底部操作区移到两栏之外、左右都让出同一块高度」，让两栏基准一致。
结果 `layout_test` 的「成语答题页 平板横屏 题干只显示一次并原位补字」红了：
题干位移 37px，因为底部区高度变化把左栏挤短了。

**这条不变量优先级高于视觉对齐**：判题前后题干跳动，孩子会觉得「刚点的字块跑了」。
最终实现是**固定预留 `_wideFooterReserve = 184`**，左右两栏都从各自可用高度里扣掉
这块，反馈内容超出时在槽位内部滚动。改这个数值要同时看：
- 判题前后 `prefixCenter.dy` / `answerCenter.dy` 是否仍在 1px 内（`layout_test` 钉着）；
- 反馈卡长正文（诗词全文）在该高度内是否够看，不够时是否正常内部滚动。

## 5. 视觉验收判据（第一批）

- [x] 1280×800 首页二级科目严格四列两行，范围卡/玩法/主按钮/次级入口全在首屏
- [x] 首页不滚动：400×800、800×1280、1280×800 三档均无溢出（`layout_test` 钉着）
- [x] 触控目标 ≥48dp，未用 `VisualDensity.compact`
- [x] 所有功能性文字对实际底色 ≥4.5:1（`inkFaint` 5.59 / `disabledText` 5.12 为底线）
- [x] 判题前后题干与选项位置变化 ≤1dp
- [x] 答对/答错同时有颜色、图标、文字三种表达
- [x] 禁用态（「请先作答」/「错题本 空」）可辨但不抢注意力
- [x] `flutter analyze` 无问题 + `flutter test` 全绿 + release APK 可出

## 6. 本批未覆盖（截图没验证到的）

- **真机字体**：所有审查截图用微软雅黑代替衬线/文楷渲染，字形与字宽和真机有差异，
  长文案的折行位置可能微调。真机上应重点看：玩法卡说明、范围卡说明、英语长句。
- 答错后的 `error` / `errorSoft` 实际观感（截图只有答对态）。
- 小于 400dp 的手机宽度（当前截图最小 400×800）。
- 系统字体放大到 1.3 倍以上时的首页（方案里写了「隐藏 tagline 与长说明」的降级规则，
  但**没有实现**）。
