# 数学科目开发计划

> 状态：规划中（2026-11-19 建立）  
> 范围：`poem_quiz` 数学科目（`kMathTopic`），在现有一年级口算基础上提高思维训练价值，并按年级拓展内容。

## 1. 目标

- **提高思维含量**：从“会算、算得快”逐步走向“懂算理、会迁移、能解释/选择方法”，让练习不只是重复求值。
- **拓展年级**：由当前仅一年级口算扩展为多学龄分档内容，使 `Topic.graded` 生效，首页可按学龄选择数学题池（题池按 `GradeLevel` 累加加权，与诗词/拼音一致）。
- **保持项目约束**：纯离线、规则生成题库（顺序确定、id 稳定）、复用现有 `Poem/Topic/QuizEngine/QuizSession` 架构，不引入后端/新依赖；改动后 `flutter test` 全绿。

## 2. 当前基线（已实现）

- 题库：`lib/data/math.dart`，`kMath` 共 196 条，**全部 grade 1**，规则生成，顺序稳定。
- 分组（5 类）：10 以内加法、10 以内减法、20 以内进位加、20 以内退位减、整十数加减。
- 题型（3 类）：`mathResult`（算得数）、`mathBlank`（填数）、`mathCompare`（比大小）。
- 条目结构：复用 `Poem` —— `title`=算式、`author`=得数、`dynasty`=分组、`lines`=含解题思路的完整算式；`MathExpr` 解析算式。
- 出题：`QuizEngine` 按 `gradeWeights` 过滤/加权；算式干扰项按数值接近度选取；比大小题随机取 `得数±1/0` 作为比较目标，三种符号都会出现。
- 学龄：因题库仅一年级，`Topic.graded` 推导为 `false`，首页隐藏学龄选择并固定用题库年级。
- 计分与机制：每题 1 分，只算对错；一局内每条算式只出一次；支持错题重练与生涯模式（按 id 记掌握）。

## 3. “提高思维”的切入点与优先级

### P0：在现有口算框架内强化“算理与数感”（优先落地）

| 方向 | 说明 | 形态/改动点 |
|---|---|---|
| 数的分与合 / 凑十基础 | 练“10 的组成”“几和几凑成 10”等，是进位加/退位减的数感基础 | 可新增条目分组（如“10的分与合”）或以填数形式呈现；仍可复用算式/填空机制或在计划中设计专用题型 |
| 多策略提示 | 同一题不只一种想法（如 12-5：破十 / 平十 / 想加算减） | 扩展 `lines`/提示结构：从单条 hint 演进为可展示的多种思路（需调整 `detailOf`/反馈展示与数据格式） |
| 加减互逆与算式家族 | 围绕同一组三数建立联系（3+4、4+3、7-3、7-4） | 内容组织上成组生成/关联；可在学习页或后续练习模式中按“家族”聚合（需设计关联键，不破坏现有 id 稳定性） |
| 比较与关系判断进阶 | 从“算完再比”走向数感比较 | 如比较两个算式结果（`3+4 □ 2+6`）、估算/不完全计算判断；需扩展题干表达与解析能力 |

### P1：增加“思考步骤”的题型与机制

| 方向 | 说明 | 备注 |
|---|---|---|
| 情境/解决问题 | 看情境列式或求解，训练迁移 | 超出现有纯算式 `MathExpr` 文本形态，需新条目表达或新题型 |
| 错因导向练习 | 按错误类型归因后针对性重练（进位漏进、退位方向、符号看错等） | 可基于现有错题本扩展记录维度与选题策略 |
| 规律与简单推理 | 数列、找规律填数等（20/100 以内） | 新题型与判题逻辑，内容需严谨 |

### P2：跨领域与更高年级思维（规划项）

- 一年级其他领域：认识图形与位置、分类与统计、认识钟表、认识人民币等（对空间/生活化思维重要，但数据模型与题型与算式不同）。
- 更高年级：表内乘除熟练与变式、估算、两步计算、简单应用题链等，随年级拓展逐步纳入。

## 4. 年级拓展路线图

> 原则：按成都现行统编版小学数学常见进度组织“难度分档”；条目必须算术正确、id 稳定可复现。`Topic.graded` 由题库跨年级情况自动推导，题库一旦覆盖多个年级，首页即展示学龄选择。

### 已纳入代码（本轮）

| 学龄 | 内容定位 | 计划分组示例 | 说明 |
|---|---|---|---|
| 一年级 | 20 以内与整十数口算（现有） | 10以内加减、20以内进位加/退位减、整十数加减 | 保留并作为低年级基础池 |
| 二年级 | 表内乘除与口算扩展 | 表内乘法、表内除法（可继续扩充 100 以内加减口算） | `MathExpr` 扩展支持 `×` `÷`，题型沿用算得数/填数/比大小 |

### 后续扩展（待实现）

| 学龄 | 候选内容 | 思维侧重点 | 前置/备注 |
|---|---|---|---|
| 三年级 | 万以内加减口算、表内乘除熟练、简单两步混合（视表达能力） | 运算顺序、估算意识 | 可能需扩展算式表达或题型 |
| 四年级 | 较大数四则口算/估算、运算律感知题 | 策略选择、简算意识 | 需控制题干复杂度与可读性 |
| 五~六年级 | 小数/分数基础口算（谨慎选取）、简便计算思路 | 数感迁移、结构识别 | 条目与解析复杂度显著上升，建议分阶段 |
| 拓展档 | 趣味算理/挑战题 | 推理与策略 | 可单列 grade 0 或独立玩法，视产品需要 |

> 注：学龄选择器当前提供 1~9 年级与“拓展”。某学龄若尚无对应专属题目，其累加池将由已实现的更低年级内容组成（符合“复习低年级”语义）；专属内容应随对应年级题库补齐。

## 5. 实现与数据约定

- **生成稳定性**：题库继续由确定性规则生成，不使用 `Random`；`Poem.id = '$dynasty|$author|$title'`（即 分组|得数|算式）必须全局唯一且跨运行稳定。
- **算式解析**：`MathExpr.of` 是出题入口；扩展运算符时需同步更新解析、结果计算、引擎出题文案与相关测试。
- **分组与年级**：`dynasty` 作为学习页分组；`grade` 决定学龄归属与累加加权。新增条目需保证同分组/全库无重复算式（按现有测试约束）。
- **提示文案**：`lines` 首行含 `（…）` 思路片段，`MathExpr.hintOf`/反馈展示依赖该格式；后续若支持多策略，需兼容或演进该约定。
- **UI/文案**：`Topic.intro`、设置/首页相关说明需随“是否分学龄”更新；`graded` 自动推导，无需手写开关。

## 6. 里程碑建议

1. **M1（本轮）**：落地开发计划文档；数学题库扩展到多学龄（至少含二年级表内乘除），启用学龄选择；补齐/更新测试。
2. **M2**：补充“10 的分与合”等数感分组与对应练习形态；优化比大小/填数的思维梯度。
3. **M3**：引入多策略提示与算式家族关联展示（不破坏 id 与存档兼容）。
4. **M4**：情境题/错因归因等新题型与数据模型扩展（按需单独立项）。

## 7. 验证

- 每次改动后执行：`flutter test`（全量，重点关注 `test/math_test.dart`、`test/layout_test.dart`、`test/quiz_engine_test.dart`）。
- 新增题型或解析规则时，为新运算符/新分组补充：可解析性、得数正确、id 唯一、各题型可出题、干扰项合法、比大小三符号覆盖等用例。
- 题库内容需保证算术事实正确（等同内容产品准确性要求）。
