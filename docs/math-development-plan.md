# 数学科目开发计划

> 状态：**主体已落地**（2026-11-19 建立，2026-11-27 更新）
> 范围：`poem_quiz` 数学科目（`kMathTopic`），一年级口算 → 一~三年级 + 思维题。
> 现行实现以 `AGENTS.md`「数据与算法约束」与 `lib/data/math.dart` 为准，本文档是设计依据与演进记录。

## 1. 目标

- **提高思维含量**：从「会算、算得快」走向「懂算理、会迁移」，让练习不只是重复求值。
- **拓展年级**：由一年级口算扩展到多学龄分档，`Topic.graded` 生效，题池按 `GradeLevel` 累加加权。
- **保持项目约束**：纯离线、规则生成题库（顺序确定、id 稳定）、复用 `Poem / Topic / QuizEngine / QuizSession`，不引入新依赖。

## 2. 当前基线（已实现，2026-11-27 核对）

- 题库：`lib/data/math.dart`，`kMath` 共 **610 条**，规则生成、顺序确定（无 `Random`），`test/math_test.dart` 用锚点钉住长度与首末 id。
- 年级分布：**一年级 196 / 二年级 162 / 三年级 130**（普通算式 488），另有思维题 **逆向填空 86 / 情境应用 36**。
- 分组（9 类 + 2 思维组）：10 以内加法、10 以内减法、20 以内进位加、20 以内退位减、整十数加减、表内乘法、表内除法、万以内加减、两位数乘一位数；`逆向填空`、`情境应用` 两组由专属题型出题，普通算式题用 `_isThinkingEntry()` 守卫排除。
- 题型（5 类）：`mathResult`（算得数）、`mathBlank`（填数）、`mathCompare`（比大小）、`mathReverse`（逆向填空）、`mathWord`（情境应用）。
- 条目结构：复用 `Poem` —— `title`=算式、`author`=得数、`dynasty`=分组、`lines`=含解题思路的完整算式；`MathExpr` 解析算式。
- 出题：`QuizEngine` 按年级权重过滤/加权；算式干扰项按数值接近度选取，`_pickFromOthers` 先去重再截窗口。
- 计分与机制：每题 1 分，只算对错；一局内每条算式只出一次；支持错题重练与生涯模式。

## 3. 「提高思维」的切入点

### P0 数感与算理（框架内，部分未做）

| 方向 | 说明 | 状态 |
|---|---|---|
| 数的分与合 / 凑十 | 「10 的组成」类数感基础 | 未做（可复用填空机制） |
| 多策略提示 | 同一题多种想法（破十 / 平十 / 想加算减） | 未做，现每条只有单条 hint |
| 加减互逆与算式家族 | 3+4、4+3、7-3、7-4 成组关联 | 未做 |
| 比较与关系判断进阶 | 从「算完再比」到数感比较 | 部分：`mathCompare` 已实现比大小 |

### P1 思考步骤（**已落地**）

| 方向 | 实现 |
|---|---|
| 逆向填空 | `mathReverse`：题面如「7 − 4 = □ + 3」，由 `_solveReverse()` 从方程反解 □（两侧皆可、已知侧可为单数字） |
| 情境应用 | `mathWord`：一句话情境（≤30 字）自己列式求值，`lines.first` 是题面、`lines.last` 是思路 |

两条铁律（详见 `AGENTS.md`「思维题」）：`title`/`author` 必须存不含 □ 的验算式与得数；情境条目 `lines` 首行不写「=」与运算符。`test/math_test.dart` 有解唯一性（0~20 穷举）与题面泄题用例。

### P2 跨领域与更高年级（规划）

- 一年级其他领域：认识图形与位置、分类与统计、认识钟表、认识人民币——数据模型与题型和算式不同，需单独立项。
- 更高年级：估算、两步计算、应用题链，随年级拓展逐步纳入（受 `MathExpr` 表达能力限制）。

## 4. 年级拓展路线图

> 原则：按成都现行统编版小学数学常见进度组织难度分档；条目算术正确、id 稳定可复现。`Topic.graded` 由题库跨年级情况自动推导。

### 已纳入代码

| 学龄 | 内容 | 分组 | 备注 |
|---|---|---|---|
| 一年级 | 20 以内与整十数口算 | 10以内加减、20以内进位加/退位减、整十数加减 | 基础池 |
| 二年级 | 表内乘除 + 100 以内加减 | 表内乘法、表内除法 | `MathExpr` 已支持 `×` `÷` |
| 三年级 | 万以内加减、两位数乘一位数 | 万以内加减、两位数乘一位数 | **不全穷举**：三位数只收整百±整百、整百+整十、整千-整百这类能口算的形态；乘法只收 11~34 × 2~5 |

### 后续扩展（未实现）

| 学龄 | 候选内容 | 前置/备注 |
|---|---|---|
| 四年级 | 较大数四则口算/估算、运算律感知 | 需控制题干复杂度 |
| 五~六年级 | 小数/分数基础口算、简便计算 | 条目与解析复杂度显著上升，分阶段 |
| 拓展档 | 趣味算理/挑战题 | 可单列 grade 0 或独立玩法 |

- **有余数除法暂时进不来**：`MathExpr` 只支持单个得数，表达不了「7 ÷ 2 = 3 余 1」，要加得先扩解析器。

## 5. 实现与数据约定

- **生成稳定性**：题库由确定性规则生成，不使用 `Random`；`Poem.id = '$dynasty|$author|$title'`（分组|得数|算式）全局唯一且跨运行稳定——错题本与生涯进度都按 id 存。
- **算式解析**：`MathExpr.of` 是出题入口；扩展运算符时需同步更新解析、结果计算、引擎出题文案与测试。
- **提示文案**：`lines.last` 是思路片段，`MathExpr.hintOf` 依赖该约定（拆算式题与思维题都取 `last`）。
- **UI/文案**：`Topic.intro`、首页说明随题库范围更新；`graded` 自动推导。
- **学龄兜底**：推算档高于三年级时，题池只含低年级条目，由累加加权自然兜底，无需特判（见 `AGENTS.md`「兜底必须分清方向」）。

## 6. 里程碑

1. **M1（已完成）**：多学龄题库（一~三年级），启用学龄选择。
2. **M2（已完成）**：逆向填空与情境应用题（`mathReverse` / `mathWord`）。
3. **M3（未做）**：「10 的分与合」等数感分组；多策略提示；算式家族关联展示。
4. **M4（未做）**：跨领域题（图形/钟表/人民币）与错因归因，需数据模型扩展，单独立项。

## 7. 验证

- 每次改动后执行：`flutter test`（重点关注 `test/math_test.dart`、`test/layout_test.dart`、`test/quiz_engine_test.dart`）。
- 新增题型或解析规则时补充：可解析性、得数正确、id 唯一、各题型可出题、干扰项合法、比大小三符号覆盖。
- 题库内容需保证算术事实正确（等同内容产品准确性要求）。
